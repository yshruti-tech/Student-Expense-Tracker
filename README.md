# Student-Expense-Tracker
A simple and user-friendly Student Expense Tracker web application designed to help students manage their daily income and expenses, understand their spending habits, and develop better saving habits. It works like a digital notebook to save the data in local Storage.

📌 About the Project
The Student Expense Tracker allows students to record their income and expenses in one place. It provides a dashboard to view financial summaries and a reports section to track savings goals.

This project was developed as a college academic project to practice web development using HTML, CSS, JavaScript, and browser Local Storage.

✨ Features
- Simple login system
-  Add income and expenses
- Select transaction categories
-  Select payment mode
-  View total income and total expenses
-  Calculate current balance
-  View recent transactions
-  Reports and savings section
-  Set a savings goal
-  Track savings progress
-  Export transaction data as CSV
- Store data using browser Local Storage
  
🛠️ Technologies Used
- HTML – Page structure
- CSS – Styling and responsive design
- JavaScript – Functionality and calculations
- Local Storage – Storing login and transaction data
- Font Awesome – Icons

🚀 How to Run
1. Download or clone this repository.
2. Extract the project folder if it is downloaded as a ZIP file.
3. Open "pg1Expense.html" in a web browser.
4. Enter the login credentials.
5. Start adding income and expenses.

«Note: This project works using browser Local Storage, so the data is stored locally in the browser.»

🔒 Security Note
This project uses Local Storage for academic purposes. It is not a production-level authentication system. Login credentials and transaction information are stored in the browser.

 Project Objective
The main objective of this project is to help students:

- Understand where their money is being spent.
- Keep track of their income and expenses.
- Monitor their available balance.
- Set and track savings goals.
- Develop better financial management and saving habits.
